# File-Handling-Utility

Duration: 4 weeks

Mentor: Neela Santosh

I developed a Java-based File Handling Utility to perform essential operations such as creating, reading, writing, and modifying a text file named “myfile.txt,” which helped me understand how files are stored, accessed, and updated in a Java application. The project was implemented using Java along with the Java Development Kit for compilation and execution, and developed in an IDE such as IntelliJ IDEA or Eclipse IDE for efficient coding and debugging. I used classes from the java.io and java.nio.file packages to manage file operations effectively. For file creation, I utilized the File class and its createNewFile() method to generate “myfile.txt” if it did not already exist, which demonstrated how Java interacts with the operating system’s file system. To write data into the file, I implemented FileWriter and BufferedWriter classes, ensuring efficient output through buffered streams that reduce the number of direct disk access operations. For reading file content, I used FileReader and BufferedReader to retrieve text line by line, which improved performance and made handling larger files easier. I also explored the Scanner class for parsing and processing file data conveniently. Since Java does not directly allow in-place modification of text files, I handled file modification by reading the existing content, storing the updated information in memory, and rewriting the entire file with the modified content, which gave me practical insight into how file updates are managed internally. Additionally, I incorporated proper exception handling using try-catch blocks to handle potential runtime errors such as IOException and FileNotFoundException, ensuring the program remains stable and user-friendly even when unexpected errors occur. This improved the robustness and reliability of the utility by preventing crashes and providing meaningful error messages. Through this project, I gained a deeper understanding of character streams versus byte streams, buffering techniques for performance optimization, file path management, and the overall lifecycle of file operations in Java. Overall, this File Handling Utility project strengthened my knowledge of Java I/O concepts, enhanced my problem-solving skills, and provided hands-on experience in implementing real-world file management functionality within a structured and object-oriented programming environment.
